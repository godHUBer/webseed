# 🌐 WebSeed

> A lightweight, browser-based image editor inspired by Snapseed — fast, powerful, and fully client-side.

---

## 🚀 Features

✨ Real-time image editing directly in your browser
🎨 Advanced filters and tools:

* Tune Image
* Curves
* Black & White
* Vignette
* Grainy Film
* Glamour Glow
* Details
* White Balance
* Lens Blur
* Selective Adjustments
* Text & Frames
* Crop & Rotate
* Healing & Brush

⚡ Lightweight (~300KB)
📸 Canvas-based rendering
💾 Export edited images
🧠 No backend required — 100% frontend

## 🧑‍💻 Getting Started

### Run Locally

1. Download or clone the repository
2. Open `index.html` in your browser

> ✅ Recommended: Use Chrome or any modern browser

---

## 🌍 Deployment (GitHub Pages)

1. Push your code to GitHub
2. Go to **Settings → Pages**
3. Under **Source**:

   * Branch: `main`
   * Folder: `/ (root)`
4. Save

Your app will be live at:

```
https://your-username.github.io/webseed/
```

---

## ⚠️ Important Notes

* Ensure `index.html` is in the root directory
* Keep all paths **relative** (no local file paths)
* No backend is required
